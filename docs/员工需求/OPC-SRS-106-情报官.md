# 情报官 员工需求规格说明

## 1. 定位与边界

情报官覆盖行业/政策监测、竞争对手、线索商机、交易对手尽调、供应商风险、市场舆情、专题简报、信息源管理与关键词订阅；是老板的外部雷达。

参考国内同类软件（用友/金蝶/钉钉/飞书/企微/销售易/纷享销客/管家婆/聚水潭/合同管理系统等）的通用功能，按中国业内标准与通用职位工作内容整理；固定步骤由工作流完成，需要理解与判断的由 AI 完成，取舍与责任仍归老板。

**边界**：
- 不把未验证信息写成事实；来源、时间、覆盖度必须标注。
- 尽调报告不构成法律/投资意见；重大合作提示律师/财务复核。
- 不采集个人隐私或违反授权/版权的内容。
- MCP/外部源不可用时标注“未获取/风险未知”，不猜测。

## 3. 功能需求

### 3.1 REQ-INT-001 行业与政策监测

**需求陈述**：监测行业趋势、政策法规、补贴/资质、监管变化；附来源与生效期。

**验收标准**：

- **AC-1** 条目含来源、发布时间、适用范围、可信度。
- **AC-2** 政策变化提示影响合同/财税/业务。
- **AC-3** 非官方来源只标“疑似”。

追溯：AC 直验

### 3.2 REQ-INT-002 竞争对手监测

**需求陈述**：跟踪竞品产品、价格、渠道、营销、融资与动态。

**验收标准**：

- **AC-1** 竞品档案与动态时间线。
- **AC-2** 对比只呈报事实，不贬损。
- **AC-3** 来源与时间可查。

追溯：AC 直验

### 3.3 REQ-INT-003 线索与商机挖掘

**需求陈述**：按行业/区域/关键词发现线索，评分、去重、分配与跟进。

**验收标准**：

- **AC-1** 线索含来源、联系方式合规性、评分依据。
- **AC-2** 高意向线索聚合提醒。
- **AC-3** 不抓取隐私/违规数据。

追溯：AC 直验

### 3.4 REQ-INT-004 交易对手尽调

**需求陈述**：对客户/供应商/合作方做工商、司法、信用、舆情、关联关系尽调。

**验收标准**：

- **AC-1** 报告含数据源、查询时间、已知盲区、免责声明。
- **AC-2** 查到风险/查无记录/源不可用三级措辞。
- **AC-3** 不构成投资/法律意见。

追溯：AC 直验

### 3.5 REQ-INT-005 供应商风险

**需求陈述**：供应商资质、履约、财务、诉讼、舆情、集中度风险。

**验收标准**：

- **AC-1** 风险等级/来源/时间可查。
- **AC-2** 风险提示备选供应商，不替老板选择。
- **AC-3** 重大风险即时提醒。

追溯：AC 直验

### 3.6 REQ-INT-006 市场与客户舆情

**需求陈述**：监测品牌、客户、行业负面/正面舆情与传播节点。

**验收标准**：

- **AC-1** 舆情含来源、时间、情绪、影响范围。
- **AC-2** 负面舆情即时提醒并转外宣/法务。
- **AC-3** 不删除/不操控舆论。

追溯：AC 直验

### 3.7 REQ-INT-007 情报简报与专题报告

**需求陈述**：按日/周/月生成简报与专题报告，附来源、结论与不确定性。

**验收标准**：

- **AC-1** 简报含要点、来源、影响、建议关注。
- **AC-2** 专题报告含方法、数据、局限。
- **AC-3** 不把推测写成事实。

追溯：AC 直验

### 3.8 REQ-INT-008 信息源管理与验证

**需求陈述**：维护来源白名单/黑名单、可信度、授权与更新频率。

**验收标准**：

- **AC-1** 来源含类型、可信度、授权、最近验证时间。
- **AC-2** 低可信来源降权/标注。
- **AC-3** 版权/授权不合规来源不采集。

追溯：AC 直验

### 3.9 REQ-INT-009 关键词/主题订阅

**需求陈述**：按公司发展关键词、客户、竞品、政策主题订阅与去重。

**验收标准**：

- **AC-1** 关键词可配置、分组、优先级。
- **AC-2** 命中去重、聚合、附来源。
- **AC-3** 未检索时标注“本次未检索”。

追溯：AC 直验

### 3.10 REQ-INT-010 情报归档与合规

**需求陈述**：情报条目/报告按保留期归档，来源可追溯，敏感信息受控。

**验收标准**：

- **AC-1** 归档带哈希、来源、版本。
- **AC-2** 导出/删除审批与审计。
- **AC-3** 个人隐私/商业秘密按权限。

追溯：AC 直验

## 4. 数据对象与视图（需求层）

| 数据对象 | 用途 |
| :--- | :--- |
| `intel_item` | 行业/政策/竞品/舆情条目 |
| `lead` | 线索/商机 |
| `dd_report` | 尽调报告与覆盖度声明 |
| `supplier_risk` | 供应商风险 |
| `source` | 信息源与可信度 |
| `watch_topic` | 关键词/主题订阅 |
| `intel_brief` | 专题简报 |

**视图**：客户/项目/合同只读；敏感客户信息不进入情报视图；外部数据标注来源与时间。

## 5. 事件、降级与审计

- **主动事件**：政策/法规更新、竞品动作、高意向线索、供应商风险、负面舆情、关键词命中、尽调到期。
- **降级**：外部数据/接口不可用时标注“未获取/需人工/数据不足”，不猜测、不伪造、不静默失败。
- **审计**：派工、工具调用、视图访问、审批/确认、导出/删除、流程实例均入审计；本分册不重复平台审计字段。
