# 行政总管 员工需求规格说明

## 1. 定位与边界

行政总管覆盖日程会议、公文制度、印章证照、办公资产、行政采购、差旅、来访接待、场地物业、IT 账号、员工入离职与考勤假期；是一人公司的行政经理 + 办公室主任。

参考国内同类软件（用友/金蝶/钉钉/飞书/企微/销售易/纷享销客/管家婆/聚水潭/合同管理系统等）的通用功能，按中国业内标准与通用职位工作内容整理；固定步骤由工作流完成，需要理解与判断的由 AI 完成，取舍与责任仍归老板。

**边界**：
- 不代老板做人事取舍、供应商选择与费用审批；只准备方案、比价与风险提示。
- 印章/证照外借、合同用印、对外公文必须审批并留痕。
- 员工个人信息、证件、考勤按最小必要与权限控制。
- 行政采购不绕过财务预算与报销制度。

## 3. 功能需求

### 3.1 REQ-ADM-001 日程与会议管理

**需求陈述**：统一管理老板日程、会议、提醒、参与人与冲突；支持线上会议链接。

**验收标准**：

- **AC-1** 日程冲突拦截；不静默覆盖。
- **AC-2** 会议关联客户/项目/合同；敏感信息按权限。
- **AC-3** 提醒按紧急度分级，夜间静默规则与主 SRS 一致。

追溯：AC 直验

### 3.2 REQ-ADM-002 会议纪要与行动项闭环

**需求陈述**：会议纪要生成、确认、行动项分派、到期提醒与关闭。

**验收标准**：

- **AC-1** 纪要需老板/主持人确认后生效。
- **AC-2** 行动项含 owner/due/状态/来源；逾期提醒。
- **AC-3** 行动项可复用为客户承诺/项目任务。

追溯：AC 直验

### 3.3 REQ-ADM-003 公文、制度与通知

**需求陈述**：公文/通知/制度起草、审批、发布、版本与签收。

**验收标准**：

- **AC-1** 模板与编号规则统一；发布前审批。
- **AC-2** 版本变更留痕；旧版可查。
- **AC-3** 签收/阅读状态可统计。

追溯：AC 直验

### 3.4 REQ-ADM-004 印章、证照与资质管理

**需求陈述**：印章使用申请、审批、登记；证照/资质/年检到期提醒。

**验收标准**：

- **AC-1** 用印必须审批并记录文件、用途、经办人。
- **AC-2** 证照借出/归还留痕；到期/年检提醒。
- **AC-3** 异常用印提示老板。

追溯：AC 直验

### 3.5 REQ-ADM-005 办公资产与设备

**需求陈述**：资产入库、领用、调拨、维修、盘点、报废。

**验收标准**：

- **AC-1** 资产台账含编号、责任人、位置、状态、折旧。
- **AC-2** 盘点差异列明原因，不静默调平。
- **AC-3** 报废/处置需审批。

追溯：AC 直验

### 3.6 REQ-ADM-006 行政采购与供应商

**需求陈述**：行政类采购申请、比价、审批、到货、验收、付款联动。

**验收标准**：

- **AC-1** 采购申请关联预算；超预算提示。
- **AC-2** 比价记录与供应商资质可查。
- **AC-3** 验收/付款与财务联动，不重复建账。

追溯：AC 直验

### 3.7 REQ-ADM-007 差旅与费用

**需求陈述**：差旅申请、行程、标准、借款、报销联动。

**验收标准**：

- **AC-1** 差旅标准可配置；超标提示。
- **AC-2** 行程/票据与报销单关联。
- **AC-3** 审批后才可订票/付款（可配置）。

追溯：AC 直验

### 3.8 REQ-ADM-008 来访、接待与后勤

**需求陈述**：访客预约、接待、门禁、会议室、餐饮/用车协调。

**验收标准**：

- **AC-1** 访客信息最小化；敏感客户按权限。
- **AC-2** 接待费用与预算/报销联动。
- **AC-3** 访客记录按保留期归档。

追溯：AC 直验

### 3.9 REQ-ADM-009 办公场地与物业

**需求陈述**：租赁、物业、水电、维修、消防、安全检查与到期提醒。

**验收标准**：

- **AC-1** 合同/租期/费用/责任人可查。
- **AC-2** 安全检查与整改闭环。
- **AC-3** 到期/续租提醒。

追溯：AC 直验

### 3.10 REQ-ADM-010 IT 账号、权限与设备

**需求陈述**：账号开通/变更/回收、设备领用、权限复核与离职回收。

**验收标准**：

- **AC-1** 入离职触发账号/设备清单。
- **AC-2** 权限按最小必要；定期复核。
- **AC-3** 异常登录/设备丢失提示。

追溯：AC 直验

### 3.11 REQ-ADM-011 员工入离职、考勤与假期

**需求陈述**：入离职手续、考勤、请假、加班、假期余额与证明。

**验收标准**：

- **AC-1** 入离职清单闭环；离职回收权限/资产。
- **AC-2** 考勤/假期规则可配置；异常提示。
- **AC-3** 个人信息按权限与保留期管理。

追溯：AC 直验

### 3.12 REQ-ADM-012 行政预算与费用分析

**需求陈述**：行政预算、实际费用、供应商/资产/差旅分析。

**验收标准**：

- **AC-1** 预算 vs 实际按科目/期间对比。
- **AC-2** 异常费用提示；不替老板削减预算。
- **AC-3** 报表带来源与 `as_of`。

追溯：AC 直验

## 4. 数据对象与视图（需求层）

| 数据对象 | 用途 |
| :--- | :--- |
| `event` | 日程/会议/提醒 |
| `action_item` | 会议行动项 |
| `document` | 公文/制度/通知/模板 |
| `seal_record` | 印章使用记录 |
| `license` | 证照/资质/年检 |
| `asset` | 办公资产/设备 |
| `purchase` | 行政采购/比价 |
| `travel` | 差旅申请/行程/报销联动 |
| `visitor` | 来访接待 |
| `it_account` | 账号/权限/设备 |
| `attendance` | 考勤/假期/入离职 |

**视图**：客户/项目只读；员工个人信息与证件按角色/字段授权；跨域明细经 `need_detail` 或令牌。

## 5. 事件、降级与审计

- **主动事件**：日程冲突、会议行动项逾期、印章/证照到期、资产盘点差异、采购超预算、差旅待审、访客到访、账号异常、合同/证照年检。
- **降级**：外部数据/接口不可用时标注“未获取/需人工/数据不足”，不猜测、不伪造、不静默失败。
- **审计**：派工、工具调用、视图访问、审批/确认、导出/删除、流程实例均入审计；本分册不重复平台审计字段。

## 6. 验收与追溯

- 本文 12 条功能需求逐条 AC 直验；平台类追溯见 `OPC-SRS-001` §12。
- 固定流程由工作流执行；需要理解/判断的由 AI 完成；取舍、承诺、审批与责任归老板/授权人。
- 插件可插拔验收：manifest 完整、启用/停用可逆、停用后不派工、卸载不误删业务数据。
