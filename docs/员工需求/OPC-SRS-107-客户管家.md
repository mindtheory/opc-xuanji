# 客户管家 员工需求规格说明

## 1. 定位与边界

客户管家覆盖客户主数据、线索转化、沟通拜访、承诺、报价、合同回款、续约流失、客户分级、投诉满意度、关系图谱、敏感信息与经营分析；是老板的 CRM/客户成功角色。

参考国内同类软件（用友/金蝶/钉钉/飞书/企微/销售易/纷享销客/管家婆/聚水潭/合同管理系统等）的通用功能，按中国业内标准与通用职位工作内容整理；固定步骤由工作流完成，需要理解与判断的由 AI 完成，取舍与责任仍归老板。

**边界**：
- 不代老板做客户取舍、报价底线、折扣与承诺；只呈报事实、历史与风险。
- 敏感字段只存私有表，跨域走一次性令牌；不进入共享视图。
- 自动提取的承诺默认待确认，不经老板确认不进入统计。
- 客户流失/续约预测标注概率与依据，不写成定论。

## 3. 功能需求

### 3.1 REQ-CRM-001 客户主数据与联系人

**需求陈述**：客户/联系人/决策链/地址/标签/分级/敏感级别统一管理。

**验收标准**：

- **AC-1** 客户去重、合并留痕；联系人关联客户。
- **AC-2** 敏感级别驱动视图/令牌。
- **AC-3** 客户状态（潜在/活跃/沉默/流失）可查。

追溯：AC 直验

### 3.2 REQ-CRM-002 线索到客户转化

**需求陈述**：线索评分、分配、跟进、转化、重复/冲突检查。

**验收标准**：

- **AC-1** 转化生成客户并保留来源。
- **AC-2** 重复客户/撞单提示，不静默合并。
- **AC-3** 高意向线索聚合提醒。

追溯：AC 直验

### 3.3 REQ-CRM-003 沟通与拜访记录

**需求陈述**：电话/微信/邮件/会议/拜访记录，关联客户/项目/承诺。

**验收标准**：

- **AC-1** 记录含时间、渠道、参与人、要点、下一步。
- **AC-2** 敏感内容按权限；可引用会话桥。
- **AC-3** 不伪造沟通记录。

追溯：AC 直验

### 3.4 REQ-CRM-004 承诺与待办追踪

**需求陈述**：承诺来源（对话/纪要/手动）、到期、状态、提醒与确认。

**验收标准**：

- **AC-1** 自动提取默认待确认；确认后计入统计。
- **AC-2** 逾期提醒；与项目/合同联动。
- **AC-3** 不替老板承诺。

追溯：AC 直验

### 3.5 REQ-CRM-005 报价与价格底线

**需求陈述**：报价历史、底线、折扣、审批与竞品对比。

**验收标准**：

- **AC-1** 报价含版本、成本依据、有效期、审批。
- **AC-2** 低于底线必须老板确认。
- **AC-3** 报价不自动对外发送。

追溯：AC 直验

### 3.6 REQ-CRM-006 合同与回款联动

**需求陈述**：客户合同、开票、回款、逾期与信用额度。

**验收标准**：

- **AC-1** 客户360视图含合同/回款/逾期汇总。
- **AC-2** 明细经视图/need_detail；不另建账。
- **AC-3** 信用风险提示，不自动停供。

追溯：AC 直验

### 3.7 REQ-CRM-007 续约与流失预警

**需求陈述**：续约窗口、沉默客户、流失风险、挽回任务。

**验收标准**：

- **AC-1** 按分级静默天数/到期前60天提醒。
- **AC-2** 预警含依据与概率，不写成定论。
- **AC-3** 挽回动作与结果留痕。

追溯：AC 直验

### 3.8 REQ-CRM-008 客户分级与 RFM

**需求陈述**：按价值/活跃/回款/潜力分级与 RFM 分析。

**验收标准**：

- **AC-1** 分级规则可配置、可解释。
- **AC-2** 分级变化留痕；不用于歧视性定价。
- **AC-3** 分析结果只呈报事实。

追溯：AC 直验

### 3.9 REQ-CRM-009 投诉与满意度

**需求陈述**：投诉登记、分级、处理、回访、满意度与改进。

**验收标准**：

- **AC-1** 投诉含来源、等级、责任人、期限、结果。
- **AC-2** 升级即时提醒；重大投诉转法务/外宣。
- **AC-3** 满意度样本与口径可查。

追溯：AC 直验

### 3.10 REQ-CRM-010 客户全景与关系图谱

**需求陈述**：客户360、决策链、关系强度、项目/合同/回款/服务历史。

**验收标准**：

- **AC-1** 全景数据带来源与 `as_of`。
- **AC-2** 关系图谱不推断隐私/敏感关系。
- **AC-3** 敏感字段脱敏。

追溯：AC 直验

### 3.11 REQ-CRM-011 客户敏感信息与隐私

**需求陈述**：敏感字段私有存储、授权、导出/删除与审计。

**验收标准**：

- **AC-1** 敏感字段只存私有表；跨域一次性令牌。
- **AC-2** 导出/删除响应个人权利请求并留痕。
- **AC-3** 不把敏感信息写入共享视图/日志。

追溯：AC 直验

### 3.12 REQ-CRM-012 客户经营分析

**需求陈述**：客户结构、贡献、留存、生命周期、获客成本与投入事实。

**验收标准**：

- **AC-1** 指标口径统一、来源可查。
- **AC-2** 投入事实视图中性排序，不构成取舍建议。
- **AC-3** 分析结果进入驾驶舱附 `as_of`。

追溯：AC 直验

## 4. 数据对象与视图（需求层）

| 数据对象 | 用途 |
| :--- | :--- |
| `customer` | 客户主档/分级/敏感级别 |
| `customer_sensitive` | 敏感字段私有存储 |
| `contact` | 联系人/决策链 |
| `lead` | 线索/转化 |
| `commitment` | 承诺/待办 |
| `quote` | 报价/底线 |
| `interaction` | 沟通/拜访记录 |
| `complaint` | 投诉/处理 |
| `satisfaction` | 满意度 |
| `segment` | 客户分级/RFM |

**视图**：客户基础信息只读；敏感字段不落视图；跨域明细经 `need_detail` 或一次性令牌。

## 5. 事件、降级与审计

- **主动事件**：沉默客户、续约窗口、承诺逾期、报价异常、投诉升级、满意度下降、客户敏感信息授权、回款逾期。
- **降级**：外部数据/接口不可用时标注“未获取/需人工/数据不足”，不猜测、不伪造、不静默失败。
- **审计**：派工、工具调用、视图访问、审批/确认、导出/删除、流程实例均入审计；本分册不重复平台审计字段。

## 6. 验收与追溯

- 本文 12 条功能需求逐条 AC 直验；平台类追溯见 `OPC-SRS-001` §12。
- 固定流程由工作流执行；需要理解/判断的由 AI 完成；取舍、承诺、审批与责任归老板/授权人。
- 插件可插拔验收：manifest 完整、启用/停用可逆、停用后不派工、卸载不误删业务数据。
