# WBS 员工 员工需求规格说明

## 1. 定位与边界

WBS 员工按项目管理标准（WBS 词典、编码、工作包、依赖、资源/工时、基线、变更、挣值）把项目目标拆成可执行、可估算、可追踪的工作分解结构；与项目监理/财务/OKR 联动。

参考国内同类软件（用友/金蝶/钉钉/飞书/企微/销售易/纷享销客/管家婆/聚水潭/合同管理系统等）的通用功能，按中国业内标准与通用职位工作内容整理；固定步骤由工作流完成，需要理解与判断的由 AI 完成，取舍与责任仍归老板。

**边界**：
- WBS 负责分解与基线，项目监理负责生命周期/排期/验收；不重复项目监理职责。
- 不代老板做范围取舍、资源优先级与验收终审。
- 未批准变更不覆盖基线；历史版本只追加。
- 成本/工时估算标注假设与区间，不写成确定值。

## 3. 功能需求

### 3.1 REQ-WBS-001 WBS 分解与词典

**需求陈述**：按交付物→工作包→任务分解，形成 WBS 词典与编码。

**验收标准**：

- **AC-1** 每个节点含编码、名称、父节点、交付物、验收标准、责任人。
- **AC-2** WBS 词典解释范围/边界/假设；编码唯一。
- **AC-3** 分解草稿需老板/项目经理确认。

追溯：AC 直验

### 3.2 REQ-WBS-002 编码规则与层级

**需求陈述**：统一编码规则、层级限制、命名规范与模板。

**验收标准**：

- **AC-1** 编码规则可配置；层级/父子无环。
- **AC-2** 模板按项目类型；变更版本化。
- **AC-3** 不符合规则拒绝导入。

追溯：AC 直验

### 3.3 REQ-WBS-003 工作包与验收标准

**需求陈述**：工作包粒度、交付物、验收标准、责任人与完成定义。

**验收标准**：

- **AC-1** 叶子工作包必须有验收标准与完成定义。
- **AC-2** 工作包可关联合同/项目/OKR。
- **AC-3** 缺失项提示补全。

追溯：AC 直验

### 3.4 REQ-WBS-004 依赖与关键路径

**需求陈述**：FS/SS/FF/SF 依赖、提前/滞后、关键路径。

**验收标准**：

- **AC-1** 依赖成环拒绝；关键路径可计算。
- **AC-2** 依赖变更提示影响。
- **AC-3** 与项目监理排期共享口径。

追溯：AC 直验

### 3.5 REQ-WBS-005 资源与工时估算

**需求陈述**：资源角色、可用容量、工时/成本估算与假设。

**验收标准**：

- **AC-1** 估算含假设、区间与依据。
- **AC-2** 资源超配提示；不自动压工期。
- **AC-3** 实际工时与估算对比。

追溯：AC 直验

### 3.6 REQ-WBS-006 基线与版本

**需求陈述**：范围/工期/成本基线快照、版本与审批。

**验收标准**：

- **AC-1** 基线批准后不可原地修改。
- **AC-2** 新版本保留历史；差异可查。
- **AC-3** 未批准变更不覆盖基线。

追溯：AC 直验

### 3.7 REQ-WBS-007 变更控制

**需求陈述**：范围/工期/成本变更单、影响评估与审批。

**验收标准**：

- **AC-1** 变更单含原因/影响/备选/审批。
- **AC-2** 影响项目/合同/财务/OKR 时提示。
- **AC-3** 重大变更 human gate。

追溯：AC 直验

### 3.8 REQ-WBS-008 进度汇总与挣值

**需求陈述**：按工时/权重汇总进度，计算 PV/EV/AC/SPI/CPI。

**验收标准**：

- **AC-1** 汇总口径统一；不出现两套数字。
- **AC-2** 偏差超阈值提醒。
- **AC-3** 预测标注假设。

追溯：AC 直验

### 3.9 REQ-WBS-009 行业模板与标准

**需求陈述**：按项目类型提供 WBS 模板、检查清单与行业实践。

**验收标准**：

- **AC-1** 模板含阶段/交付物/工作包/角色。
- **AC-2** 模板变更版本化；不覆盖运行中项目。
- **AC-3** 不适用时提示裁剪。

追溯：AC 直验

### 3.10 REQ-WBS-010 与项目/财务/OKR 联动

**需求陈述**：与项目监理、财税成本、OKR 对齐；数据同源。

**验收标准**：

- **AC-1** WBS 进度供项目监理排期/甘特。
- **AC-2** 成本估算与实际经财务汇总。
- **AC-3** OKR 关联权重合计 ≤100%。

追溯：AC 直验

## 4. 数据对象与视图（需求层）

| 数据对象 | 用途 |
| :--- | :--- |
| `wbs_node` | 工作包/任务/交付物/验收标准 |
| `wbs_dictionary` | WBS 词典与编码规则 |
| `wbs_baseline` | 基线快照/版本 |
| `wbs_change` | 范围/工期/成本变更 |
| `wbs_dependency` | 依赖/关键路径 |
| `wbs_resource` | 资源/工时估算 |
| `wbs_evm` | 挣值/偏差 |

**视图**：项目/合同/OKR 只读；成本明细经 `need_detail`；WBS 数据按项目权限。

## 5. 事件、降级与审计

- **主动事件**：WBS 基线批准/变更、关键路径变化、工作包逾期、成本偏差、范围蔓延、模板更新。
- **降级**：外部数据/接口不可用时标注“未获取/需人工/数据不足”，不猜测、不伪造、不静默失败。
- **审计**：派工、工具调用、视图访问、审批/确认、导出/删除、流程实例均入审计；本分册不重复平台审计字段。

## 6. 验收与追溯

- 本文 10 条功能需求逐条 AC 直验；平台类追溯见 `OPC-SRS-001` §12。
- 固定流程由工作流执行；需要理解/判断的由 AI 完成；取舍、承诺、审批与责任归老板/授权人。
- 插件可插拔验收：manifest 完整、启用/停用可逆、停用后不派工、卸载不误删业务数据。
