# 货栈总管 员工需求规格说明

## 1. 定位与边界

货栈总管覆盖 SKU、仓库库位、采购供应商、入库出库、调拨、盘点、批次序列号效期、库存预警补货、成本核算、发票税负联动与库存分析；是一人公司的进销存/仓储主管。

参考国内同类软件（用友/金蝶/钉钉/飞书/企微/销售易/纷享销客/管家婆/聚水潭/合同管理系统等）的通用功能，按中国业内标准与通用职位工作内容整理；固定步骤由工作流完成，需要理解与判断的由 AI 完成，取舍与责任仍归老板。

**边界**：
- 不代老板做采购取舍、供应商选择、定价与补货决策；只呈报库存、成本、缺货与风险。
- 出入库四要素不全不落库；低置信度必须确认。
- 成本计价方法一经选定不随意切换；变更留痕。
- 库存/批次/效期以实际盘点与凭证为准，不猜测。

## 3. 功能需求

### 3.1 REQ-INV-001 SKU 与商品主数据

**需求陈述**：SKU 编码、名称、别名、规格、单位、条码、税率、安全库存、状态。

**验收标准**：

- **AC-1** SKU 唯一编码；别名映射唯一。
- **AC-2** 停用 SKU 不得新出入库。
- **AC-3** 与采购/销售/发票关联。

追溯：AC 直验

### 3.2 REQ-INV-002 仓库与库位

**需求陈述**：仓库、库位、区域、容量、负责人、状态。

**验收标准**：

- **AC-1** 库位唯一；库存按仓库/库位汇总。
- **AC-2** 调拨/移库留痕。
- **AC-3** 盘点按库位。

追溯：AC 直验

### 3.3 REQ-INV-003 采购与供应商

**需求陈述**：采购申请/订单、供应商、比价、到货、验收、退货。

**验收标准**：

- **AC-1** 采购订单含 SKU/数量/单价/交期/税率。
- **AC-2** 到货差异/退货留痕。
- **AC-3** 供应商风险引用情报官。

追溯：AC 直验

### 3.4 REQ-INV-004 入库管理

**需求陈述**：采购入库、退货入库、调拨入库、其他入库；四要素确认。

**验收标准**：

- **AC-1** 四要素（SKU/数量/单价/相对方）不全不落库。
- **AC-2** 低置信度确认卡；发票状态可标。
- **AC-3** 入库生成库存与应付线索。

追溯：AC 直验

### 3.5 REQ-INV-005 出库管理

**需求陈述**：销售出库、项目领料、调拨出库、其他出库；成本结转。

**验收标准**：

- **AC-1** 出库校验库存/批次/权限。
- **AC-2** 项目领料关联项目/合同。
- **AC-3** 出库生成成本与应收线索。

追溯：AC 直验

### 3.6 REQ-INV-006 调拨与移库

**需求陈述**：跨仓/跨库位调拨、在途、签收与差异。

**验收标准**：

- **AC-1** 调拨单含源/目标/数量/在途状态。
- **AC-2** 差异留痕；不静默调平。
- **AC-3** 调拨成本按规则结转。

追溯：AC 直验

### 3.7 REQ-INV-007 盘点与差异

**需求陈述**：盘点计划、实盘、差异、复盘、调整与审批。

**验收标准**：

- **AC-1** 盘点按仓库/库位/SKU；差异原因必填。
- **AC-2** 调整需审批；历史盘点可查。
- **AC-3** 不自动覆盖账面。

追溯：AC 直验

### 3.8 REQ-INV-008 批次、序列号与效期

**需求陈述**：批次/序列号/生产日期/有效期/先进先出。

**验收标准**：

- **AC-1** 出入库可追踪批次/序列号。
- **AC-2** 效期临近/过期预警；先进先出提示。
- **AC-3** 召回/追溯可查。

追溯：AC 直验

### 3.9 REQ-INV-009 库存预警与补货

**需求陈述**：安全库存、周转、滞销、缺货、补货建议。

**验收标准**：

- **AC-1** 预警含 SKU/仓库/数量/依据。
- **AC-2** 补货建议含销量/在途/交期，不替老板下单。
- **AC-3** 滞销/积压提示。

追溯：AC 直验

### 3.10 REQ-INV-010 成本核算与计价

**需求陈述**：先进先出/加权平均/移动平均等计价；成本结转与差异。

**验收标准**：

- **AC-1** 计价方法选定后变更留痕。
- **AC-2** 成本与财务同源，不另建账。
- **AC-3** 成本异常提示复核。

追溯：AC 直验

### 3.11 REQ-INV-011 发票与税负联动

**需求陈述**：进项/销项发票、缺票、税率、税负预估。

**验收标准**：

- **AC-1** 缺票入库挂账并月末汇总。
- **AC-2** 进销项与库存/采购/销售勾稽。
- **AC-3** 税负仅参考，不替代申报。

追溯：AC 直验

### 3.12 REQ-INV-012 库存分析与报表

**需求陈述**：库存金额、周转、库龄、呆滞、缺货、毛利分析。

**验收标准**：

- **AC-1** 指标口径/来源/`as_of` 可查。
- **AC-2** 异常提示；不替老板做清仓/补货决定。
- **AC-3** 报表可导出并附脚注。

追溯：AC 直验

## 4. 数据对象与视图（需求层）

| 数据对象 | 用途 |
| :--- | :--- |
| `sku` | SKU/别名/单位/安全库存 |
| `stock_txn` | 出入库/冲正 |
| `warehouse` | 仓库/库位 |
| `supplier` | 供应商 |
| `purchase_order` | 采购订单 |
| `transfer` | 调拨 |
| `inventory_count` | 盘点/差异 |
| `batch` | 批次/序列号/效期 |
| `replenish` | 补货建议 |
| `cost_sheet` | 成本计价/结转 |

**视图**：库存汇总只读；客户/项目/合同只读；成本明细经 `need_detail` 或令牌。

## 5. 事件、降级与审计

- **主动事件**：库存告急/滞销、缺票入库积压、盘点差异、效期临近、批次异常、采购到货延迟、供应商风险、成本异常。
- **降级**：外部数据/接口不可用时标注“未获取/需人工/数据不足”，不猜测、不伪造、不静默失败。
- **审计**：派工、工具调用、视图访问、审批/确认、导出/删除、流程实例均入审计；本分册不重复平台审计字段。

## 6. 验收与追溯

- 本文 12 条功能需求逐条 AC 直验；平台类追溯见 `OPC-SRS-001` §12。
- 固定流程由工作流执行；需要理解/判断的由 AI 完成；取舍、承诺、审批与责任归老板/授权人。
- 插件可插拔验收：manifest 完整、启用/停用可逆、停用后不派工、卸载不误删业务数据。
