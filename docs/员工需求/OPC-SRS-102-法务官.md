# 法务官 员工需求规格说明

## 1. 定位与边界

法务官覆盖合同全生命周期、公司治理、诉讼纠纷、知识产权、劳动人事合规、法规监测、法律文书与外部律师协同；既是法务经理也是合同管理员与合规官。

参考国内同类软件（用友/金蝶/钉钉/飞书/企微/销售易/纷享销客/管家婆/聚水潭/合同管理系统等）的通用功能，按中国业内标准与通用职位工作内容整理；固定步骤由工作流完成，需要理解与判断的由 AI 完成，取舍与责任仍归老板。

**边界**：
- 不替代律师出具法律意见；重大合同/诉讼提示外部律师复核。
- 不代老板决定是否签约、是否起诉、是否和解；只呈报事实、条款风险、方案与成本。
- 条款风险扫描只标风险与建议，不判定违法或胜诉概率。
- 合同/案件/证据原文按权限与保密要求存储，敏感信息不进入共享视图。

## 3. 功能需求

### 3.1 REQ-LEG-001 合同全生命周期管理

**需求陈述**：覆盖起草、评审、签署、履约、变更、续签、归档；合同版本、相对方、金额、期限、交付物、付款节点齐全。

**验收标准**：

- **AC-1** 合同状态机覆盖草稿/评审/签署/履约/变更/续签/终止/归档；状态迁移写审计。
- **AC-2** 合同版本不可覆盖；变更/补充协议引用原合同。
- **AC-3** 到期/续签/付款节点进入提醒。

追溯：AC 直验

### 3.2 REQ-LEG-002 合同风险扫描与条款库

**需求陈述**：按风险规则库扫描条款，输出条款级标红、修改建议、依据与免责声明。

**验收标准**：

- **AC-1** 每条建议带规则来源与版本；不输出“违法/必胜”结论。
- **AC-2** 高风险条款（无限责任、自动续约、单方解除、知识产权归属）强制人工复核。
- **AC-3** 扫描结果附“不构成法律意见”声明。

追溯：AC 直验

### 3.3 REQ-LEG-003 合同履约与异常

**需求陈述**：跟踪交付、付款、验收、违约、担保与保密义务；异常进入提醒与案件线索。

**验收标准**：

- **AC-1** 履约节点可关联项目/回款/发票。
- **AC-2** 违约/逾期/争议生成异常卡与证据清单。
- **AC-3** 不自动发律师函或对外主张权利。

追溯：AC 直验

### 3.4 REQ-LEG-004 公司治理与股权合规

**需求陈述**：维护股东、股权、董事/监事、章程、决议、工商变更与合规节点。

**验收标准**：

- **AC-1** 治理文件版本化；决议与工商变更留痕。
- **AC-2** 股权/章程/注册资本变更提示法务与财税复核。
- **AC-3** 不代老板做股权分配/控制权安排。

追溯：AC 直验

### 3.5 REQ-LEG-005 诉讼仲裁与纠纷管理

**需求陈述**：登记案件、对手、标的、证据、律师、节点、费用与结果；跟踪时效与执行。

**验收标准**：

- **AC-1** 案件状态/节点/费用/结果可查；证据链版本化。
- **AC-2** 重大案件提示外部律师；不预测胜诉概率。
- **AC-3** 和解/撤诉/上诉必须老板确认。

追溯：AC 直验

### 3.6 REQ-LEG-006 知识产权管理

**需求陈述**：商标/专利/著作权/商业秘密的申请、维护、到期、许可与侵权线索。

**验收标准**：

- **AC-1** 资产台账含权利人、类别、申请号、有效期、年费/续展。
- **AC-2** 到期/年费/续展提醒；许可/转让合同关联。
- **AC-3** 侵权线索只提示核查，不判定侵权。

追溯：AC 直验

### 3.7 REQ-LEG-007 劳动人事合规

**需求陈述**：劳动合同、员工手册、竞业限制、保密、社保公积金、用工风险检查。

**验收标准**：

- **AC-1** 合同/手册/竞业/保密模板版本化；签署与到期留痕。
- **AC-2** 用工风险清单（未签合同、试用期、加班、社保）提示补正。
- **AC-3** 不代老板做解除/处罚决定。

追溯：AC 直验

### 3.8 REQ-LEG-008 合规日历与法规更新

**需求陈述**：按行业/地区维护法规、监管、资质、年检、备案节点；法规更新提示影响。

**验收标准**：

- **AC-1** 法规来源、文号、生效日、适用范围可查。
- **AC-2** 更新影响现有合同/制度/流程时提示复核。
- **AC-3** 非官方来源只记录“疑似”，不进入正式清单。

追溯：AC 直验

### 3.9 REQ-LEG-009 法律文书与模板库

**需求陈述**：合同、函件、授权、决议、通知、律师函等模板；变量填充与审批。

**验收标准**：

- **AC-1** 模板版本化；变量必填校验。
- **AC-2** 对外函件/律师函必须审批；不自动发送。
- **AC-3** 模板与条款库关联，变更有记录。

追溯：AC 直验

### 3.10 REQ-LEG-010 外部律师与机构协同

**需求陈述**：律师/律所入库、委托、费用、进度、成果与评价；利益冲突检查。

**验收标准**：

- **AC-1** 委托事项、范围、费用、节点、成果可查。
- **AC-2** 利益冲突提示；费用与预算对比。
- **AC-3** 外部意见与内部意见并列，不混为定论。

追溯：AC 直验

### 3.11 REQ-LEG-011 法务档案与证据链

**需求陈述**：合同/案件/律师函/证据/授权按保留期归档，哈希与权限控制。

**验收标准**：

- **AC-1** 归档文件带版本、哈希、来源与访问记录。
- **AC-2** 证据链可按时间线查看；导出审批。
- **AC-3** 删除/作废必须确认并留痕。

追溯：AC 直验

### 3.12 REQ-LEG-012 法务风险报告与培训

**需求陈述**：按月/季输出合同、诉讼、合规、知识产权、劳动风险报告与培训建议。

**验收标准**：

- **AC-1** 报告带数据截止时间、来源与风险等级。
- **AC-2** 培训/制度更新建议可跟踪闭环。
- **AC-3** 不把风险报告写成法律意见。

追溯：AC 直验

## 4. 数据对象与视图（需求层）

| 数据对象 | 用途 |
| :--- | :--- |
| `contract` | 合同主档：相对方、金额、期限、履约、变更、续签、冻结 |
| `risk_rule` | 合同/合规风险规则库与条款模板 |
| `legal_case` | 诉讼/仲裁/纠纷案件与进度 |
| `ip_asset` | 商标/专利/著作权/商业秘密 |
| `labor_doc` | 劳动合同/员工手册/竞业/保密 |
| `compliance_item` | 合规日历与法规更新事项 |
| `legal_opinion` | 法律意见/风险提示/外部律师意见 |
| `legal_archive` | 合同/案件/证据归档 |

**视图**：合同/客户/项目只读；客户敏感字段不进入法务视图；跨域明细经 `need_detail` 或一次性令牌。

## 5. 事件、降级与审计

- **主动事件**：合同到期/续签、重大条款风险、履约异常、诉讼节点、知识产权到期、劳动合规风险、法规更新、外部律师费用。
- **降级**：外部数据/接口不可用时标注“未获取/需人工/数据不足”，不猜测、不伪造、不静默失败。
- **审计**：派工、工具调用、视图访问、审批/确认、导出/删除、流程实例均入审计；本分册不重复平台审计字段。

## 6. 验收与追溯

- 本文 12 条功能需求逐条 AC 直验；平台类追溯见 `OPC-SRS-001` §12。
- 固定流程由工作流执行；需要理解/判断的由 AI 完成；取舍、承诺、审批与责任归老板/授权人。
- 插件可插拔验收：manifest 完整、启用/停用可逆、停用后不派工、卸载不误删业务数据。
