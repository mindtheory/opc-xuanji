# 战略参谋 员工需求规格说明

## 1. 定位与边界

战略参谋覆盖战略规划、年度经营计划、OKR、预算与资源分配、经营分析复盘、决策管理、市场/竞争战略、商业模式、组织人才与投资合作评估；是老板的战略与经营分析搭档。

参考国内同类软件（用友/金蝶/钉钉/飞书/企微/销售易/纷享销客/管家婆/聚水潭/合同管理系统等）的通用功能，按中国业内标准与通用职位工作内容整理；固定步骤由工作流完成，需要理解与判断的由 AI 完成，取舍与责任仍归老板。

**边界**：
- 不代老板做战略取舍、资源优先级、投资/合作决策；只呈报事实、方案、假设与风险。
- 经营预测标注假设与区间，不写成确定值。
- OKR 调整、预算削减、重大投资必须老板确认。
- 分析结论可溯源，不把相关性写成因果。

## 3. 功能需求

### 3.1 REQ-STR-001 战略规划与年度经营计划

**需求陈述**：形成公司愿景/目标/年度重点/举措/资源需求，版本化审批。

**验收标准**：

- **AC-1** 计划含目标、举措、责任人、预算、里程碑、衡量指标。
- **AC-2** 版本变更留痕；不覆盖历史。
- **AC-3** 不替老板做战略取舍。

追溯：AC 直验

### 3.2 REQ-STR-002 OKR 目标管理

**需求陈述**：目标/关键结果设定、对齐、进度回卷、复盘与权重。

**验收标准**：

- **AC-1** OKR 含 owner、周期、权重、信心指数、进度来源。
- **AC-2** 进度回卷标注来源与 `as_of`；冻结数据加脚注。
- **AC-3** 调整目标必须老板确认。

追溯：AC 直验

### 3.3 REQ-STR-003 预算与资源分配

**需求陈述**：年度/季度预算、部门/项目/费用预算、执行对比与调整。

**验收标准**：

- **AC-1** 预算 vs 实际按期间/科目/项目对比。
- **AC-2** 超预算/偏差提示；调整走审批。
- **AC-3** 不自动削减预算。

追溯：AC 直验

### 3.4 REQ-STR-004 经营分析与复盘

**需求陈述**：收入、成本、利润、现金流、客户、项目、人效等经营分析。

**验收标准**：

- **AC-1** 指标口径统一；来源与 `as_of` 可查。
- **AC-2** 同比/环比/结构/排名/预算对比。
- **AC-3** 结论不写成因果或取舍建议。

追溯：AC 直验

### 3.5 REQ-STR-005 决策管理

**需求陈述**：议题、背景、选项、假设、评估、决策、执行与复盘留痕。

**验收标准**：

- **AC-1** 决策卡含选项/利弊/风险/责任人/期限。
- **AC-2** 决策与冲突裁决/合同/投资可关联。
- **AC-3** AI 只呈报选项，不替老板选择。

追溯：AC 直验

### 3.6 REQ-STR-006 市场与竞争战略

**需求陈述**：市场容量、竞争格局、客户需求、渠道/定价策略分析。

**验收标准**：

- **AC-1** 来源、时间、覆盖度标注；不虚构数据。
- **AC-2** 竞品对比含事实与差距，不含贬损。
- **AC-3** 结论供参考，不替代老板判断。

追溯：AC 直验

### 3.7 REQ-STR-007 商业模式与产品组合

**需求陈述**：商业模式画布、产品/服务组合、收入结构、定价与毛利分析。

**验收标准**：

- **AC-1** 假设与敏感性可查。
- **AC-2** 产品/客户盈利只呈报事实。
- **AC-3** 不输出“砍掉某产品”的结论。

追溯：AC 直验

### 3.8 REQ-STR-008 组织与人才战略

**需求陈述**：组织架构、关键岗位、能力缺口、激励与人才计划。

**验收标准**：

- **AC-1** 岗位/能力/编制/成本可查。
- **AC-2** 人才评价只呈报事实与缺口，不做人员取舍。
- **AC-3** 敏感人事信息按权限。

追溯：AC 直验

### 3.9 REQ-STR-009 投资、合作与并购评估

**需求陈述**：投资/合作/并购机会、标的、协同、风险、估值区间与退出。

**验收标准**：

- **AC-1** 评估含假设、来源、风险与情景。
- **AC-2** 不承诺回报；重大事项提示律师/财务复核。
- **AC-3** 决策与投后跟踪留痕。

追溯：AC 直验

### 3.10 REQ-STR-010 战略风险与情景分析

**需求陈述**：政策/市场/竞争/资金/组织风险与多情景推演。

**验收标准**：

- **AC-1** 情景含假设、触发条件、影响与应对。
- **AC-2** 风险等级与责任人可跟踪。
- **AC-3** 预测标注区间，不写成确定值。

追溯：AC 直验

## 4. 数据对象与视图（需求层）

| 数据对象 | 用途 |
| :--- | :--- |
| `strategy_plan` | 战略规划/年度经营计划 |
| `objective` | OKR/目标与关键结果 |
| `budget` | 预算与资源分配 |
| `review` | 经营分析/复盘 |
| `decision` | 决策议题/方案/结论/跟踪 |
| `scenario` | 情景与敏感性分析 |
| `investment_case` | 投资/合作/并购评估 |

**视图**：客户/项目/合同/财务只读；客户敏感字段不进入战略视图；跨域明细经 `need_detail` 或令牌。

## 5. 事件、降级与审计

- **主动事件**：年度计划节点、OKR 风险、预算偏差、经营指标异常、重大决策待确认、投资/合作节点、季度复盘。
- **降级**：外部数据/接口不可用时标注“未获取/需人工/数据不足”，不猜测、不伪造、不静默失败。
- **审计**：派工、工具调用、视图访问、审批/确认、导出/删除、流程实例均入审计；本分册不重复平台审计字段。

## 6. 验收与追溯

- 本文 10 条功能需求逐条 AC 直验；平台类追溯见 `OPC-SRS-001` §12。
- 固定流程由工作流执行；需要理解/判断的由 AI 完成；取舍、承诺、审批与责任归老板/授权人。
- 插件可插拔验收：manifest 完整、启用/停用可逆、停用后不派工、卸载不误删业务数据。
