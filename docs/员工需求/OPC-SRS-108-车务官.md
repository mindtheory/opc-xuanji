# 车务官 员工需求规格说明

## 1. 定位与边界

车务官覆盖车辆档案、驾驶员、用车申请调度、行程里程、加油充电、保养维修、保险年检、违章事故、私车公用合规、费用归集、车辆处置与成本分析；是一人公司的车队管理员+车务合规角色。

参考国内同类软件（用友/金蝶/钉钉/飞书/企微/销售易/纷享销客/管家婆/聚水潭/合同管理系统等）的通用功能，按中国业内标准与通用职位工作内容整理；固定步骤由工作流完成，需要理解与判断的由 AI 完成，取舍与责任仍归老板。

**边界**：
- 不代老板做车辆购置/处置、驾驶员奖惩、事故责任认定；只呈报事实、成本与风险。
- 私车公用补贴只认官方标准与完整凭证；缺协议/里程拦截入账。
- 违章/事故责任以交管/保险认定为准，AI 不判定责任。
- 车辆定位/轨迹涉及个人信息时按授权与最小必要。

## 3. 功能需求

### 3.1 REQ-VEH-001 车辆档案与证照

**需求陈述**：车辆基本信息、证照、保险、年检、归属与状态。

**验收标准**：

- **AC-1** 车辆含车牌、车型、归属、购置/折旧、证照到期。
- **AC-2** 证照/保险/年检到期提醒。
- **AC-3** 车辆处置/过户留痕。

追溯：AC 直验

### 3.2 REQ-VEH-002 驾驶员管理

**需求陈述**：驾驶员资质、准驾、培训、违章/事故记录与授权。

**验收标准**：

- **AC-1** 驾驶员档案含证件有效期、准驾车型。
- **AC-2** 资质过期/违章未处理提示。
- **AC-3** 不替老板做奖惩/解除决定。

追溯：AC 直验

### 3.3 REQ-VEH-003 用车申请与调度

**需求陈述**：用车申请、审批、车辆/驾驶员分配、行程与归还。

**验收标准**：

- **AC-1** 申请含事由、时间、人数、目的地、项目/客户。
- **AC-2** 冲突/超配提示；审批后调度。
- **AC-3** 行程结束归还/费用登记。

追溯：AC 直验

### 3.4 REQ-VEH-004 行程与里程

**需求陈述**：出车/收车里程、路线、事由、乘车人、项目归属。

**验收标准**：

- **AC-1** 里程与油量/电耗可核对。
- **AC-2** 异常里程/路线提示。
- **AC-3** 行程与项目/客户关联。

追溯：AC 直验

### 3.5 REQ-VEH-005 加油充电与能耗

**需求陈述**：加油/充电记录、单价、金额、里程、油耗/电耗。

**验收标准**：

- **AC-1** 记录含时间、站点、金额、里程。
- **AC-2** 油耗/电耗异常提示。
- **AC-3** 与报销/成本归集联动。

追溯：AC 直验

### 3.6 REQ-VEH-006 保养与维修

**需求陈述**：保养计划、维修工单、配件/工时、供应商、费用与下次提醒。

**验收标准**：

- **AC-1** 保养按里程/时间提醒。
- **AC-2** 维修工单含项目/金额/凭证。
- **AC-3** 大额维修需审批。

追溯：AC 直验

### 3.7 REQ-VEH-007 保险年检与证照

**需求陈述**：保险投保/续保、年检、营运证、环保/安检。

**验收标准**：

- **AC-1** 到期前提醒；脱保/漏检即时提示。
- **AC-2** 保单/凭证归档。
- **AC-3** 不自动投保。

追溯：AC 直验

### 3.8 REQ-VEH-008 违章与事故

**需求陈述**：违章查询/处理、事故登记、责任认定、保险理赔与费用。

**验收标准**：

- **AC-1** 违章/事故含时间、地点、处理状态、费用。
- **AC-2** 责任以交管/保险认定为准，AI 不判定。
- **AC-3** 重大事故即时提醒老板。

追溯：AC 直验

### 3.9 REQ-VEH-009 私车公用合规

**需求陈述**：私车公用协议、里程、补贴标准、凭证与个税提示。

**验收标准**：

- **AC-1** 补贴只认官方标准与完整凭证。
- **AC-2** 缺协议/里程拦截入账。
- **AC-3** 计算结果标注“参考值，以主管税务机关认定为准”。

追溯：AC 直验

### 3.10 REQ-VEH-010 费用归集与单车成本

**需求陈述**：油/电/保险/维修/路桥/停车/折旧/补贴按车辆/项目归集。

**验收标准**：

- **AC-1** 费用与财务/项目同源，不另建账。
- **AC-2** 单车成本/每公里成本可算。
- **AC-3** 异常费用提示。

追溯：AC 直验

### 3.11 REQ-VEH-011 车辆处置与折旧

**需求陈述**：车辆购置、折旧、处置、残值、过户与税务处理提示。

**验收标准**：

- **AC-1** 折旧/处置留痕；税务处理提示财税复核。
- **AC-2** 处置需老板审批。
- **AC-3** 历史成本可查。

追溯：AC 直验

### 3.12 REQ-VEH-012 车务分析与提醒

**需求陈述**：车辆利用率、成本、风险、到期、驾驶员行为分析。

**验收标准**：

- **AC-1** 指标口径/来源/`as_of` 可查。
- **AC-2** 异常/风险提示；不替老板做处置决定。
- **AC-3** 报告进入驾驶舱/简报。

追溯：AC 直验

## 4. 数据对象与视图（需求层）

| 数据对象 | 用途 |
| :--- | :--- |
| `vehicle` | 车辆档案/证照/状态 |
| `driver` | 驾驶员/资质 |
| `trip` | 用车申请/行程/里程 |
| `fuel` | 加油/充电/能耗 |
| `maintenance` | 保养/维修 |
| `insurance` | 保险/年检 |
| `violation` | 违章/事故 |
| `vehicle_log` | 用车台账/费用 |
| `subsidy_standard` | 私车公用补贴标准 |

**视图**：车辆汇总只读，费用明细脱敏；客户/项目只读；跨域明细经 `need_detail` 或令牌。

## 5. 事件、降级与审计

- **主动事件**：车辆脱保/漏检、保养到期、违章未处理、事故、私车公用缺凭证、油耗异常、车辆闲置、补贴标准候选。
- **降级**：外部数据/接口不可用时标注“未获取/需人工/数据不足”，不猜测、不伪造、不静默失败。
- **审计**：派工、工具调用、视图访问、审批/确认、导出/删除、流程实例均入审计；本分册不重复平台审计字段。

## 6. 验收与追溯

- 本文 12 条功能需求逐条 AC 直验；平台类追溯见 `OPC-SRS-001` §12。
- 固定流程由工作流执行；需要理解/判断的由 AI 完成；取舍、承诺、审批与责任归老板/授权人。
- 插件可插拔验收：manifest 完整、启用/停用可逆、停用后不派工、卸载不误删业务数据。
