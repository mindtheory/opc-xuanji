# 外宣员工 员工需求规格说明

## 1. 定位与边界

外宣员工覆盖品牌与传播策略、外宣计划/内容日历、新闻稿与媒体关系、自媒体运营（公众号/视频号/抖音/小红书）、内容素材版权、发布审批、危机公关舆情、活动展会、效果监测与渠道供应商管理；是老板的品牌公关/新媒体负责人。

参考国内同类软件（用友/金蝶/钉钉/飞书/企微/销售易/纷享销客/管家婆/聚水潭/合同管理系统等）的通用功能，按中国业内标准与通用职位工作内容整理；固定步骤由工作流完成，需要理解与判断的由 AI 完成，取舍与责任仍归老板。

**边界**：
- 只生成草稿与建议；对外发布必须老板/授权人审批，高风险内容 hold。
- 不虚构案例/数据/客户评价；客户案例需授权。
- 不承诺媒体发稿/流量/转化结果；渠道数据不可用时标“未回收”。
- 危机公关不替老板决定回应口径与法律责任；提示律师/公关顾问复核。

## 3. 功能需求

### 3.1 REQ-PUB-001 品牌与传播策略

**需求陈述**：品牌定位、受众、信息屋、渠道策略、年度传播主题。

**验收标准**：

- **AC-1** 策略含目标、受众、核心信息、渠道、预算、衡量。
- **AC-2** 版本化；变更留痕。
- **AC-3** 不替老板定品牌承诺。

追溯：AC 直验

### 3.2 REQ-PUB-002 外宣计划与内容日历

**需求陈述**：按目标/节点制定外宣计划、内容日历、渠道与排期。

**验收标准**：

- **AC-1** 计划含主题/渠道/受众/时间/负责人。
- **AC-2** 排期冲突提示。
- **AC-3** 未批准计划不进入发布队列。

追溯：AC 直验

### 3.3 REQ-PUB-003 新闻稿与媒体关系

**需求陈述**：新闻稿起草、媒体名单、 pitching、采访、发稿与回执。

**验收标准**：

- **AC-1** 稿件标注 AI 草稿/待核实；引用带来源。
- **AC-2** 媒体关系含记者/媒体/领域/历史。
- **AC-3** 不承诺发稿/流量。

追溯：AC 直验

### 3.4 REQ-PUB-004 自媒体运营

**需求陈述**：公众号/视频号/抖音/小红书等平台内容、发布、互动与数据。

**验收标准**：

- **AC-1** 内容按平台适配；发布前审批。
- **AC-2** 评论/私信敏感内容转人工。
- **AC-3** 数据不可用时标“未回收”。

追溯：AC 直验

### 3.5 REQ-PUB-005 内容素材与版权

**需求陈述**：图片/视频/字体/音乐素材、授权、版权与到期。

**验收标准**：

- **AC-1** 素材含来源、授权、期限、使用范围。
- **AC-2** 版权缺失提示替换。
- **AC-3** 客户案例/肖像需授权。

追溯：AC 直验

### 3.6 REQ-PUB-006 发布审批与合规

**需求陈述**：发布前审批、敏感词/广告法/客户案例/金额检查。

**验收标准**：

- **AC-1** 高风险内容 hold；审批前不得发布。
- **AC-2** 广告法/敏感词提示，不判定违法。
- **AC-3** 审批/驳回/撤回留痕。

追溯：AC 直验

### 3.7 REQ-PUB-007 危机公关与舆情

**需求陈述**：负面舆情监测、分级、回应口径、发布与复盘。

**验收标准**：

- **AC-1** 危机分级/责任人/时限；重大危机即时提醒。
- **AC-2** 回应口径需老板/律师确认。
- **AC-3** 不删除/不操控舆论。

追溯：AC 直验

### 3.8 REQ-PUB-008 活动与展会

**需求陈述**：活动策划、预算、报名、物料、执行、复盘。

**验收标准**：

- **AC-1** 活动含目标/预算/责任人/节点/物料。
- **AC-2** 费用与财务联动。
- **AC-3** 复盘含数据与改进。

追溯：AC 直验

### 3.9 REQ-PUB-009 效果监测与复盘

**需求陈述**：阅读/互动/转化/线索/媒体曝光与渠道对比。

**验收标准**：

- **AC-1** 指标含来源、口径、`as_of`。
- **AC-2** 未回收不填 0；不虚构效果。
- **AC-3** 复盘输出可复用经验。

追溯：AC 直验

### 3.10 REQ-PUB-010 渠道与供应商管理

**需求陈述**：媒体/代运营/设计/活动供应商入库、比价、合同、评价。

**验收标准**：

- **AC-1** 供应商含资质/报价/合同/评价。
- **AC-2** 利益冲突/合规风险提示。
- **AC-3** 不替老板选择供应商。

追溯：AC 直验

## 4. 数据对象与视图（需求层）

| 数据对象 | 用途 |
| :--- | :--- |
| `publication_plan` | 外宣计划/内容日历 |
| `publication` | 内容/渠道/排期/状态 |
| `publication_approval` | 发布审批 |
| `channel_account` | 渠道账号 |
| `media_contact` | 媒体/记者关系 |
| `content_asset` | 素材/版权/授权 |
| `campaign` | 活动/展会 |
| `crisis_case` | 舆情/危机 |
| `publicity_metric` | 阅读/互动/转化 |

**视图**：客户/项目/合同/OKR 只读；客户敏感字段不进入素材；跨域明细经 `need_detail` 或令牌。

## 5. 事件、降级与审计

- **主动事件**：外宣待审、发布失败、渠道异常、负面舆情、媒体询问、活动节点、版权到期、指标未回收。
- **降级**：外部数据/接口不可用时标注“未获取/需人工/数据不足”，不猜测、不伪造、不静默失败。
- **审计**：派工、工具调用、视图访问、审批/确认、导出/删除、流程实例均入审计；本分册不重复平台审计字段。

## 6. 验收与追溯

- 本文 10 条功能需求逐条 AC 直验；平台类追溯见 `OPC-SRS-001` §12。
- 固定流程由工作流执行；需要理解/判断的由 AI 完成；取舍、承诺、审批与责任归老板/授权人。
- 插件可插拔验收：manifest 完整、启用/停用可逆、停用后不派工、卸载不误删业务数据。
