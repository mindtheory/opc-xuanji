# 财税管家 员工需求规格说明

## 1. 定位与边界

财税管家不是单一记账工具，而是**一人公司的财务总监 + 会计 + 税务 + 工商上报 + 经营分析**综合角色：

| 视角 | 职责 |
| :--- | :--- |
| 财务总监 | 预算与资金、财务分析、内控、税筹方案、重大财务事项提示、报表审阅 |
| 会计 | 会计科目、凭证、账簿、期末结账、三表生成、账账/账实/账表核对 |
| 出纳/报销 | 报销凭证、发票与附件、付款/收款、银行流水勾稽 |
| 税务 | 税种与申报日历、税负监控、加计扣除等专业事项、税筹落地跟踪 |
| 工商/统计 | 年报、月报、季报等对外上报的数据准备、口径核对、审批与留痕 |
| 合规 | 公私边界、凭证真实性、审计追踪、政策来源与版本标注 |

**边界**：

- 不代替老板做经营取舍、利润分配、关联交易定价等决策；只呈报事实、方案、风险与建议。
- 不伪造、不篡改、不补造凭证；缺凭证只提示补证或挂账，不生成虚假票据。
- 税筹只给**合法合规方案与风险对比**，不承诺节税结果；重大事项提示税务师/律师复核。
- 加计扣除、税收优惠、工商上报以**政策原文与主管机关认定**为准；AI 只做草稿、校验与提醒。
- 不替代外部审计机构、税务师事务所、律师事务所出具法定意见。

## 3. 功能需求

### 3.1 REQ-FIN-001 财务职责矩阵与角色定位

**需求陈述**：财税管家覆盖财务总监、会计、出纳/报销、税务、工商上报与经营分析职责；每类任务标明责任边界、所需审批与外部专业复核点。

**验收标准**：

- **AC-1** 任务卡必须标注角色视角（财务总监/会计/出纳/税务/工商/分析）与是否涉及老板裁决。
- **AC-2** 涉及利润分配、关联交易、重大投资、税务筹划取舍的任务只呈报方案与风险，不自动执行。
- **AC-3** 涉及法定审计、税务鉴证、工商异常处理的任务必须提示外部专业机构复核。
- **AC-4** 职责矩阵与工具族、视图、单员工流程一一对应，不出现“有职责无工具/有工具无边界”。

追溯：AC 直验

### 3.2 REQ-FIN-002 公私边界与凭证合规

**需求陈述**：台账区分公司/个人主体；公司账户支付个人类支出时给出公私混同风险信号；凭证缺失/不合规时提示补证，不生成虚假凭证。

**验收标准**：

- **AC-1** 台账记录含 `entity`（公司/个人）、`amount`、`direction`、`category`、`invoice_id`、`project_id`、`note`、`conflict_frozen`。
- **AC-2** 公司账户支付个人类支出产生“公私混同嫌疑”即时事件，文案为“风险信号”，不出现违法判定措辞。
- **AC-3** 凭证缺失、抬头错误、金额不一致、重复报销时拒绝自动入账并提示补证/冲正。
- **AC-4** 被冻结记录不参与汇总，但出现在“含冻结”总额与脚注中。

追溯：AC 直验

### 3.3 REQ-FIN-003 报销凭证全生命周期管理

**需求陈述**：覆盖报销申请、票据采集、OCR/发票查验、审批、付款、入账、归档、冲正与查询；支持差旅、招待、办公、交通、通讯、房租、水电、研发等费用类型。

**验收标准**：

- **AC-1** `reimbursement_voucher` 记录申请人、费用类型、金额、税额、事由、项目/客户、票据清单、审批状态、付款状态、入账凭证号、归档位置。
- **AC-2** 票据附件支持发票、收据、行程单、支付凭证；每张票据记录类型、号码、金额、税额、开票方、查验状态与原件路径。
- **AC-3** 同一发票号/同一支付凭证重复报销时拦截；发票查验失败或抬头不符时进入人工确认。
- **AC-4** 报销单审批通过后才生成付款/记账凭证；冲正生成反向记录并引用原单，不删除原记录。
- **AC-5** 报销政策（额度、标准、必需附件）可配置；超标准时提示并要求老板/财务总监确认。

追溯：AC 直验 / `test/unit/employees.test.ts`（manifest）

### 3.4 REQ-FIN-004 会计科目与辅助核算管理

**需求陈述**：按公司经营范围维护会计科目表、辅助核算维度与账簿；科目变更留痕，历史凭证口径不被静默改写。

**验收标准**：

- **AC-1** `account_subject` 含科目编码、名称、类别（资产/负债/权益/成本/损益）、级次、父科目、余额方向、是否明细、启用状态。
- **AC-2** 辅助核算支持客户、供应商、项目、部门、员工、合同、发票等维度；同一科目可按维度组合查询。
- **AC-3** 科目新增/停用/改名必须留痕；已使用科目不得删除，停用后不得新凭证引用。
- **AC-4** 科目表可按经营范围模板初始化（服务/贸易/制造/混合），模板变更不覆盖已发生凭证。
- **AC-5** 科目与报表项目映射可配置；映射变更只影响新报表，历史报表保留原口径与版本。

追溯：AC 直验

### 3.5 REQ-FIN-005 日常账务处理与期末结账

**需求陈述**：支持凭证录入/导入、审核、记账、期末结转、结账与反结账；账账、账实、账表可核对。

**验收标准**：

- **AC-1** `accounting_voucher` 含凭证号、日期、期间、摘要、附件数、制单/审核/记账人、状态；分录含科目、借/贷金额、辅助核算。
- **AC-2** 借贷不平衡、科目停用、期间已结账时拒绝记账；审核与制单不得为同一人（单老板场景可配置强提醒）。
- **AC-3** 期末结转（损益结转、税费计提、折旧摊销）生成固定模板凭证，可 dry-run 预览。
- **AC-4** 结账前必须完成银行/现金/存货/往来核对；未完成项列清单，不静默结账。
- **AC-5** 反结账必须老板/财务总监确认并写审计；已对外报送期间默认禁止反结账。

追溯：UC-004 / AC 直验

### 3.6 REQ-FIN-006 财务报表管理、统计与汇总

**需求陈述**：按期间生成资产负债表、利润表、现金流量表及管理报表；支持多期间统计、同比/环比、汇总与下钻。

**验收标准**：

- **AC-1** `financial_statement` 含报表类型、期间、口径版本、生成时间、数据来源、编制人、审核状态、冻结标记。
- **AC-2** 三表之间勾稽关系可校验（资产=负债+权益、利润表净利润与权益变动/现金流量表逻辑一致）；差异必须列明原因。
- **AC-3** 支持月度/季度/年度、多期间对比、项目/客户/部门汇总；汇总口径与明细可追溯。
- **AC-4** 报表只读快照保存 `as_of`；源数据变更后不自动覆盖已审报表，需重出并标注版本。
- **AC-5** 报表导出 CSV/PDF，文件头写 `schema_version`、期间、口径版本与冻结脚注。

追溯：AC 直验

### 3.7 REQ-FIN-007 月度/年度三表生成与审计

**需求陈述**：按月、按年生成资产负债表、利润表、现金流量表，并支持报表审计：勾稽校验、异常波动、凭证抽样、审计底稿与差异说明。

**验收标准**：

- **AC-1** 月度三表在结账后生成；年度三表在年度结转后生成；未结账/未结转时只生成草稿并标注“未审”。
- **AC-2** 报表审计必查：三表勾稽、期初期末衔接、科目余额方向、异常波动（阈值可配）、大额/关联方交易、跨期费用。
- **AC-3** 审计发现差异时生成“差异说明卡”，记录差异金额、可能原因、建议动作与责任人；不自动改数。
- **AC-4** 审计底稿保存校验规则、样本清单、凭证引用、结论与复核人；底稿只追加不覆盖。
- **AC-5** 年度三表对外使用前必须老板/财务总监确认；涉及法定审计时提示外部审计机构复核。

追溯：AC 直验 / `annual_financial_report` 流程

### 3.8 REQ-FIN-008 财务审计与内控

**需求陈述**：提供凭证抽查、账实/账账/账表核对、权限与职责分离检查、异常交易监控、内控缺陷清单与整改跟踪。

**验收标准**：

- **AC-1** 支持按金额、科目、供应商、客户、项目、期间、制单人抽样；抽样规则可配置并留痕。
- **AC-2** 账实核对覆盖银行、现金、存货、固定资产；差异生成盘点/调节表，不静默调平。
- **AC-3** 职责分离检查覆盖制单/审核/付款/记账；单老板场景给出“无法完全分离”的显式风险提示与补偿控制。
- **AC-4** 异常交易监控覆盖大额、整数、频繁、跨期、关联方、个人账户、深夜操作等模式；命中只提示，不判定违法。
- **AC-5** 内控缺陷清单含等级、影响、建议、责任人、期限与整改状态；整改完成需复核。

追溯：AC 直验

### 3.9 REQ-FIN-009 税务核算、申报与税负监控

**需求陈述**：按税种维护申报日历、计提、申报、缴纳与凭证；监控税负率、进销项匹配、留抵、附加税费与优惠适用。

**验收标准**：

- **AC-1** `tax_calendar` 含税种、期间、截止日、状态、来源版本；距截止 ≤7 天预警并入晨报。
- **AC-2** `tax_filing` 含税种、期间、计税依据、应纳税额、减免额、已缴/未缴、申报状态、凭证号、官方回执。
- **AC-3** 税负率输出带“行业参考值 + 来源 + 版本 + 非税务认定”标注；异常波动提示核查，不直接定性。
- **AC-4** 进销项、发票、台账、申报表可勾稽；差异列明原因，不自动调平。
- **AC-5** 税收优惠/加计扣除必须引用政策原文、适用期与文号；候选不参与计算，确认后才生效。

追溯：UC-006（Verifier 侧）/ `tax_monthly_prepare` 流程

### 3.10 REQ-FIN-010 工商、统计等对外上报

**需求陈述**：支持工商年报、月报、季报、统计报表等对外上报的数据准备、口径核对、审批、提交记录与回执归档。

**验收标准**：

- **AC-1** `business_report` 含报表类型、所属期间、报送机关、口径版本、数据来源、编制/审核人、提交状态、回执/截图、截止日。
- **AC-2** 上报数据与财务报表、税务申报、社保/公积金数据交叉核对；差异列明原因，不直接改数。
- **AC-3** 对外提交前必须老板/财务总监确认；提交失败保留草稿与错误信息，不伪造成功回执。
- **AC-4** 年报、月报、季报、统计报表的截止日进入申报日历与提醒；逾期风险提示。
- **AC-5** 上报口径与政策版本留痕；政策变化时提示复核，不静默沿用旧口径。

追溯：AC 直验

### 3.11 REQ-FIN-011 研发费用加计扣除等会计专业事项

**需求陈述**：支持研发项目辅助账、研发费用归集、加计扣除计算与备查资料管理；覆盖其他会计专业事项（资产折旧、摊销、存货计价、收入确认、政府补助等）的规则提示。

**验收标准**：

- **AC-1** 研发项目辅助账按项目归集人员人工、直接投入、折旧、无形资产摊销、设计/试验/委托研发等费用；凭证与辅助账可追溯。
- **AC-2** 加计扣除计算引用政策文号、适用期间、扣除比例与限制条件；只生成计算底稿与申报草稿，不代替税务机关认定。
- **AC-3** 备查资料清单（立项、人员、工时、费用分配、合同、发票、成果）可检查完整性；缺失项提示补证。
- **AC-4** 资产折旧/摊销、存货计价、收入确认、政府补助等专业事项提供规则提示与口径来源；不确定项标注“需专业复核”。
- **AC-5** 加计扣除/优惠金额进入税务申报草稿前必须人工确认；审计保留计算版本与依据。

追溯：AC 直验

### 3.12 REQ-FIN-012 按经营范围完善财务核算

**需求陈述**：根据公司经营范围（服务、贸易、零售、制造、混合等）配置收入、成本、费用、存货、固定资产、薪酬、社保公积金、税费等核算口径与报表模板。

**验收标准**：

- **AC-1** 公司档案中的经营范围/主体类型映射到核算模板；模板包含科目、辅助核算、报表项目与常见凭证模板。
- **AC-2** 服务型：项目/合同收入、人工成本、差旅/招待/办公费用、进项抵扣；贸易/零售：采购、库存、销售成本、平台费用、运费、退货；制造：材料、人工、制造费用、在产品/产成品。
- **AC-3** 收入确认、成本结转、费用归属口径可配置；变更留痕，不覆盖历史凭证。
- **AC-4** 薪酬、社保、公积金、个税、残保金等事项有固定检查清单；缺项提示。
- **AC-5** 经营范围变化时提示复核核算模板与税种/申报事项，不自动切换历史口径。

追溯：AC 直验

### 3.13 REQ-FIN-013 税筹方案与落地跟踪

**需求陈述**：针对业务场景生成合法合规的税筹方案对比（适用条件、节税逻辑、风险、成本、落地步骤），跟踪执行与复盘；不承诺节税结果。

**验收标准**：

- **AC-1** 税筹方案必须列明政策依据、适用条件、假设、计算过程、风险与不确定性；无依据不得生成。
- **AC-2** 至少提供“维持现状/方案 A/方案 B”对比，含税负、现金流、合规成本、执行难度；不替老板选择。
- **AC-3** 方案落地生成任务清单（主体/合同/发票/申报/账务/资料），执行状态可跟踪。
- **AC-4** 风险提示覆盖虚开、关联交易、常设机构、社保、个税、转让定价等红线；涉及重大事项提示税务师/律师复核。
- **AC-5** 方案与执行记录归档审计；政策变化时提示复审，不自动沿用。

追溯：AC 直验

### 3.14 REQ-FIN-014 财务分析与经营支持

**需求陈述**：提供现金流、利润、成本、费用、应收应付、税负、项目/客户盈利、预算执行等分析；结论可溯源，不替老板决策。

**验收标准**：

- **AC-1** 分析指标带口径、期间、来源与 `as_of`；冻结事件按“含冻结 + 脚注”口径。
- **AC-2** 支持趋势、同比/环比、结构、排名、预算 vs 实际；异常波动提示原因待查。
- **AC-3** 项目/客户盈利分析只呈报事实与敏感性，不输出“应放弃某客户”等取舍结论。
- **AC-4** 现金流预测标注假设与区间，不把预测写成确定值。
- **AC-5** 分析结果进入驾驶舱/简报时附来源与数据截止时间。

追溯：AC 直验

### 3.15 REQ-FIN-015 财务档案、审计追踪与数据治理

**需求陈述**：凭证、报表、申报、上报、税筹、加计扣除等资料按保留期归档；全流程可审计；敏感财务数据按权限与最小必要访问。

**验收标准**：

- **AC-1** 会计凭证类 ≥30 年、合同类按合同期 +5 年、一般操作日志 ≥5 年；归档文件带 `schema_version` 与 SHA-256。
- **AC-2** 凭证/报表/申报/上报/税筹的创建、修改、审核、导出、删除均写审计；审计不落敏感原文。
- **AC-3** 删除/作废必须老板/财务总监确认；已归档资料只追加不覆盖。
- **AC-4** 敏感财务数据按角色/视图授权；导出审批与留痕；离职/外包权限及时回收。
- **AC-5** 数据迁移/口径升级提供迁移脚本与回滚预案，历史报表保留原版本可读。

追溯：AC 直验 / 主 SRS §7 审计

## 5. 事件、降级与审计

- **主动事件**：公私混同嫌疑、现金流红灯、税务申报预警、缺票积压、报销超标准/重复票、报表勾稽差异、结账未完成、工商上报截止、加计扣除资料缺失、税筹方案待确认、审计异常交易。
- **降级**：发票查验/银行/工商/税务/外部 MCP 不可用时标注“未查验/未获取/需人工”，不伪造回执、不猜测税额、不自动调平。
- **审计**：派工、工具调用、视图访问、报销审批、凭证审核/记账、结账/反结账、报表生成/审计、申报/上报、税筹确认、导出/删除均入审计。
