## 3. 关键决策

| # | 决策 | 理由 | 代价/风险 |
| :--- | :--- | :--- | :--- |
| ADR-01 | 一人一份 SRS 分册 | 员工需求可独立评审、安装、交付 | 主 SRS 需维护索引与一致性 |
| ADR-02 | manifest 为唯一装配事实 | 不维护硬编码员工名单 | 需校验视图/工具/写目标 |
| ADR-03 | 安装默认停用，启用二次确认 | 防止导入即产生写入 | 多一步操作 |
| ADR-04 | 员工包用 JSON 信封 v1 | 不引入 zip 依赖，易校验/审计 | 大文件 base64 体积偏大 |
| ADR-05 | 包默认不含业务数据/凭据 | 防泄露；数据迁移走独立流程 | 迁移需额外数据导出 |
| ADR-06 | 停用前检查依赖插件 | 防止 WBS/外宣依赖断裂 | 停用顺序有约束 |
| ADR-07 | 导入失败事务回滚 | 不留半安装状态 | 需单事务覆盖包/插件/任务 |
