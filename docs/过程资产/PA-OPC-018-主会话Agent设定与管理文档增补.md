## 1. 变更原因

老板要求：主会话 Agent 不能只是“问答机器人”，要主动沟通、主动汇报、主动摸清老板和公司情况、主动规划实现公司目标的路径并主动推进执行；同时要控制节奏，不给老板阅读与决策压力。所有需要老板裁决、审批、决议的事项，必须给可行方案与推荐，一屏内可读、可选择。

原文档体系已有 SRS/IRS/SDD/DBDD/STP/STD/STR/SUM，但缺少：

1. 主会话 Agent 的人格、职责、工作循环、汇报节奏、裁决卡规范与验收。
2. 软件工程管理类文档：开发计划、配置管理、质量保证、风险管理、需求追踪矩阵、版本说明。
